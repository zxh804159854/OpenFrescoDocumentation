# TangentForceConverter 实验信号滤波器
新增命令，暂无解释。

## 命令
```tcl
expSignalFilter TangentForceConverter tag -initStif Kij -tangStif tangStifTag
```

| 参数 | 说明 |
|:----|:-----|
| $tag | 唯一实验信号滤波器标签 |
