# OpenFrescoDocumentation

## 项目说明

本项目为 **OpenFresco 官方文档的中文翻译版本**，基于最新版本的 OpenFresco 命令体系进行整理与更新。

文档内容采用 **AI 辅助翻译 + 人工校对与排版** 的方式完成，在尽量保证术语准确性的同时，提高整体可读性与结构清晰度。

⚠️ **版权声明**：

* 原始文档版权归 OpenFresco 原作者及其团队所有
* 本项目仅用于学习、研究与交流，不涉及商业用途

## 项目特点

* ✅ 与最新 OpenFresco 命令保持同步
* ✅ 结构清晰，便于查阅与学习
* ✅ 持续更新与修订中

## 使用说明

如果你在使用过程中发现：

* 翻译不准确
* 术语不统一
* 排版问题

欢迎提交 Issue 或 Pull Request 共同完善。
